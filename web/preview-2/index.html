Важные детали

Коротко о том, как работает сервис и что стоит учитывать при обработке изображений.

Это фоторедактор?

Image resizer — сервис изменения размера изображений, а не фоторедактор.

Что означает «р.» в ценах?

«Р.» — внутренние баллы сервиса, не денежные средства. Сайт не является публичной офертой.

Всегда ли результат ИИ будет точным?

Изображения обрабатываются автоматически, в том числе с помощью ИИ. Результат может содержать неточности — проверяйте его перед загрузкой.

Можно ли загружать документы и личные фотографии?

Сервис не предназначен для конфиденциальных данных: не загружайте документы и чувствительные изображения. Исходники и результаты могут просматриваться администратором для контроля качества.

Условия использования

Image resizer — сервис изменения размера изображений, а не фоторедактор. Не является публичной офертой; «р.» — внутренние баллы сервиса, не денежные средства.

Изображения обрабатываются автоматически, в том числе с помощью ИИ. Результат может содержать неточности — проверяйте его перед загрузкой.

Сервис не предназначен для конфиденциальных данных: не загружайте документы и чувствительные изображения. Исходники и результаты могут просматриваться администратором для контроля качества.

Запрещается использовать сервис для создания или изменения изображений в целях введения третьих лиц в заблуждение, совершения противоправных действий либо нарушения прав и законных интересов третьих лиц.

Для работы сервиса и аналитики могут обрабатываться история запросов и технические данные. Метаданные (EXIF, GPS, ИИ-метки) из результата удаляются.
