Image resizer — прототип сервиса. Не является публичной офертой; «р.» — внутренние баллы сервиса, не денежные средства.

Изображения обрабатываются автоматически с помощью ИИ-моделей (GigaChat, Google Gemini через OpenRouter). Результат может содержать неточности — проверяйте его перед загрузкой.

Сервис не предназначен для конфиденциальных данных: не загружайте документы и чувствительные изображения. Исходники и результаты могут просматриваться администратором для контроля качества и модерации.

Запрещено загружать незаконный контент, подделывать документы, печати и подписи, изменять внешность на фото для документов, обрабатывать изображения других людей без их согласия. Такие запросы отклоняются.

Мы храним идентификатор Telegram, историю запросов и технические данные для работы сервиса и аналитики. Метаданные (EXIF, GPS, ИИ-метки) из результата удаляются.
